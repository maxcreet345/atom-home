# Atom Home — универсальная панель для Home Assistant

Одна панель для любого дома: устройства распознаются по типам HA, владелец или сервисный центр выбирает в конфигураторе, что показывать. Устанавливается через HACS (интеграция + панель). Дизайн-система V18 (светлая и тёмная темы), русский/румынский/английский.

Структура:
- `frontend/` — панель (Preact + TypeScript + Vite), конфигуратор, изолированный просмотр на снимке HA.
- `custom_components/atom_home/` — интеграция HA: регистрация панели, хранение конфигурации дома и фото (этап 3).
- `docs/` — архитектура, модель устройств, план этапов, журнал выпусков.
- `private/` — локальные снимки реестров и конфигураций домов (не публикуется).

Установка: `docs/INSTALL.md`. Этапы: `docs/PLAN.md`. Статус — этап 3 (HACS и установка).
