# Установка Atom Home через HACS

1. HACS → ⋮ → **Custom repositories** → добавить `https://github.com/maxcreet345/atom-home`, тип **Integration**.
2. Найти «Atom Home» в HACS, нажать **Download**, затем **перезапустить Home Assistant**.
3. Настройки → Устройства и службы → **Добавить интеграцию** → «Atom Home» (одна копия на дом).
4. В боковом меню появится **Atom Home**. Администратор открывает в панели «Настройка» и выбирает, что показывать; конфигурация хранится в `.storage/atom_home.config` этого HA.

Что ставится: `custom_components/atom_home/` — интеграция (панель в боковом меню, WebSocket API `atom_home/config/get|set` и `atom_home/photo/set|delete`, хранилище конфигурации в `.storage`, фото владельца в `<config>/atom_home/photos/`) и собранный фронтенд `frontend/atom-home.js` с типовыми иллюстрациями. Внешних зависимостей нет, токены не хранятся: панель работает в сессии вошедшего пользователя HA.

Помощники, которые интеграция читает, но не создаёт (Настройки → Устройства и службы → Помощники, id ровно такие): `input_boolean.alarm_ringing` и `input_text.alarm_ringing` (максимальная длина 255) — баннер будильника и «Стоп»; `input_text.atom_light_sleep` (максимальная длина 255) — «Выключится в …» в листе света. Если помощника нет или текст короче 255, после запуска HA в «Настройки → Исправления» появится предупреждение Atom Home; после создания помощника перезапустите HA. При выключении или удалении интеграции эти предупреждения снимаются; при перезагрузке записи помощники проверяются заново.

Что открыто без входа в HA: `/atom_home/loader.js` (загрузчик панели), `/atom_home/meta` (только отметка текущего пакета, без версии) и `/atom_home/bundle.js` (код панели; отдаётся со сжатием gzip тем, кто его принимает, сжатая копия делается один раз на сборку; на `HEAD` — те же заголовки без файла, так что `curl -sI` годится для проверки; `If-None-Match` понимает слабую отметку `W/"…"`, список отметок и `*` → 304). Фото владельца лежат в `/atom_home_photos/` под неугадываемыми именами.

Обновление: HACS → Atom Home → Update → перезапуск HA (именно перезапуск: «Перезагрузить» на карточке интеграции оставляет в памяти прежний Python, и панель продолжит напоминать о перезапуске). Откат: HACS → Atom Home → Redownload → выбрать прежнюю версию. Конфигурация дома при обновлении и откате сохраняется.

Экспорт конфигурации для сервисного центра: «Настройка» → «Дом» → «Экспорт JSON» → сохранить в `clients/<дом>/atom-home-config-<дата>.json`.
