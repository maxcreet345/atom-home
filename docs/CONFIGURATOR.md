# Конфигуратор (этап 2)

Открывается из бокового меню («Настройка») или из «Ещё» на телефоне; виден только администраторам HA (`host.admin`). Каждое изменение сразу применяется к панели (повторный `discover()`) и сохраняется в хранилище: в превью — `localStorage` (`atom-home:config`), в HA — интеграция (этап 3). Все правки проходят `normaliseConfig`: небезопасные ключи, неверные сервисы и мусор отбрасываются с предупреждением, панель никогда не падает из-за конфигурации.

| Вкладка | Что можно |
|---|---|
| Устройства | поиск; по комнатам; переключатель «показывать»; раскрыть карточку: название, комната, вид, значок, «объединить с» (той же комнаты), порядок; список сущностей прибора с кнопкой «скрыть» (и возврат скрытых); фото прибора |
| Комнаты | показывать/скрыть, название, порядок, фото (иначе типовая иллюстрация по названию); «Без комнаты» тоже настраивается |
| Разделы | скрыть любой раздел кроме Обзора и Комнат |
| Кнопки | список кнопок владельца; конструктор: подпись, сервис (подсказки из реестра сервисов HA), сущность, данные JSON, значок, «спрашивать подтверждение» (по умолчанию включено) |
| Модули | обнаруженные модули (сейчас: котёл eBUS) с переключателем и полями сущностей по ролям; обязательные роли помечены * |
| Дом | название, язык (ru/ro/en), тема, логотип; экспорт JSON, импорт JSON, сброс правок |

Сценарный QA (`frontend/scripts/qa-setup.mjs`): скрыть устройство → исчезает из «Систем» и сохраняется; переименовать комнату → имя везде; добавить кнопку → появляется на Обзоре, спрашивает подтверждение, вызывает ровно один сервис с указанной сущностью; экспорт → валидный JSON; импорт → язык меняется и сохраняется.
