# Этап 8 — дизайн «homeOS» (Apple HomeView) (28.10.2026)

Владелец попросил оформление «1 в 1 как у Apple HomeView / homeOS». Изучены страница Apple, пресс-релиз с изображениями лиц и hands-on в прессе; ключевой ориентир — лицо **Home Modular** (сетка квадратных модулей: часы, термостат 2×2, камера, сцены, аксессуары). Дизайн-система описана в [DESIGN-HOMEOS.md](DESIGN-HOMEOS.md).

## Сделано (v0.8.0)
- Новая таблица стилей `frontend/src/styles/apple.css` заменила `home.css` + `theme-light.css` (старый «Мой дом» v2/V18 скин); `atom.css` оставлен только для модулей (котёл, кормушка, камера, иллюстрации).
- Экран «Дом» — одно лицо Home Modular: `ClockTile`, `ThermostatTile` (2×2, шевроны меняют цель через runner), `CameraTile` (2×2 с живым go2rtc), компактные карточки модулей как модули показаний, `SceneTile` для кнопок владельца, `ValueTile` (погода, CO₂, энергия, протечки), затем все аксессуары: сначала управляемые, потом остальные климат-приборы, потом датчики. Имя без повторения комнаты (`inRoomName`), комната второй строкой.
- Навигация: Дом · Комнаты · Системы · Настройка; прежние экраны Свет/Климат/Уборка/Энергия/Системы — сегменты внутри «Системы» (хэши `#lights` и т. д. сохранены). Планшет — рельс иконок, телефон — матовый таб-бар.
- Комната: пилюли показаний + модули по группам; Климат — термостаты 2×2 и карточка котла; Системы/Свет — модули по группам; Уборка — широкий модуль + действия; Энергия — карточки с полосой.
- Темы: светлая (как `home-touch`) и тёмная (как настенный HomeView на бирюзовых обоях) — переключаются прежней настройкой «Тема».
- Тесты 22/22; QA конфигуратора 25/25, кормушки 26/26, живого элемента 13/13 (навигация в QA переведена на хэши, проверки — на модули). Снимки телефон/планшет в обеих темах: `frontend/evidence/stage8-light/`, `stage8-dark/`.

## Criuleni
v0.8.0 накатан через HACS без перезапуска (только фронтенд). Вживую: лицо из 48 модулей, часы, термостат «21» («Отопление дома»), камера LIVE 2×2, давление котла 0,79 bar, три сцены, 9 модулей света; «Системы» — 22 модуля, «Климат» — 7 термостатов + котёл; телефон — 3 колонки, карточка устройства открывается; ответов ≥400 и ошибок страницы нет. Снимки `frontend/evidence/stage8-criuleni/`. Панель «Мой дом» (home18) не тронута, в Траян не ставилось.

## Замечания
- Физические планшет/iPhone владельца не проверялись (как и HD камеры).
- Лиловый тинт активного модуля виден, когда что-то включено; на снимках всё выключено.
