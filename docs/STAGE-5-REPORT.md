# Этап 5 — модуль «Камера go2rtc» (28.10.2026)

## Что сделано
- **Модуль `camera_go2rtc`** (`frontend/src/modules/camera-go2rtc.tsx`, плеер `go2rtc-player.ts`, чистые помощники `go2rtc-protocol.ts`): живое видео по MSE из add-on go2rtc через его ingress (`/api/hassio_ingress/<token>/api/ws?src=<поток>`). Ingress-адрес и сессия берутся у Supervisor через авторизованный WebSocket HA (`supervisor/api`), cookie ставится в той же области, что и у штатного фронтенда HA; токены нигде не хранятся. Поддерживаются H.264/H.265 (+ Opus/AAC), браузер решает через `MediaSource.isTypeSupported`; на iPhone — `ManagedMediaSource`.
- **Обнаружение**: generic-камера с именем Supervisor `camera.<slug>_go2rtc` → slug add-on подставляется сам. Поток: заданный в настройках, иначе первый из `api/streams` (предпочтительно с «h264/sd/sub» в имени). Второй поток — HD; переключатель HD/SD в карточке камеры; если браузер не декодирует HD (H.265 без MSE-поддержки), плеер возвращается на SD и гасит кнопку (v0.5.1).
- **Куда встроен**: вместо стоп-кадра в плитке камеры на Обзоре и в карточке устройства (новая зона `stage` в `DeviceSheet`); бейдж LIVE, состояния «Подключаем видео… / прервалось / недоступно». Плеер останавливается при скрытой вкладке и отключённом HA, переподключается с задержкой 3→6→12→24 с; очередь ≤4 МБ.
- **Каркас модулей**: у модуля появились свободные настройки `options` (строки `[\w.-]{1,64}`, ключи `\w{1,32}`) — редактируются во вкладке «Модули», хранятся в `modules[id].options`, обязательные помечены *; `Host.ws` даёт модулям сырой WebSocket (в превью отсутствует — модуль показывает «Нет связи» без ошибок).
- Тесты 16/16 (+3: помощники протокола — slug, ingress-путь, сессия, MIME, выбор потока; нормализация options; обнаружение в снимке Criuleni и слияние настроек). QA конфигуратора 21/21 (+4: модуль обнаружен с подсказкой slug, поток сохраняется, плеер смонтирован на Обзоре, сцена в карточке). ## Проверка в Criuleni (v0.5.0 → v0.5.1 через HACS, без перезапуска HA)
Конфиг дома дополнен `modules.camera_go2rtc.options = { stream: criuleni_c700_h264, streamHd: criuleni_c700 }`. Живая проверка через сессию HA: плитка Обзора — LIVE, 640×362, кадры идут (17→78→190 кадров, время растёт); карточка камеры — LIVE; HD в headless Chromium (без HEVC) → после v0.5.1 откат на SD, кнопка погашена; телефон 390×844 — LIVE; ответов ≥400 и ошибок страницы нет. Снимки `frontend/evidence/stage5-criuleni/`. HD на планшете/iPhone владельца не проверялся (там HEVC обычно есть).

## Замечания
- При открытой карточке камеры одновременно идут два потока (плитка позади и сцена) — на SD это ~1 Мбит/с; при желании плитку можно ставить на паузу.
- Кормушка Траяна и типовые изображения приборов остаются отложенными.
