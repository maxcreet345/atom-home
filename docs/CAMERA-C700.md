# Карточка камеры: Подъезд · Xiaomi Smart Camera C700 (chuangmi.camera.081ae2)

Спецификация перед реализацией (04.11.2026). Источники: полный MIoT-spec v2 камеры (31 сервис), сущности HA (xiaomi_miot + 13 шаблонных помощников + Generic Camera через go2rtc), экраны приложения Mi Home на OnePlus Open (`frontend/evidence/mihome-c700/`), книга дома `book/03-devices/entrance-camera.md`, панель HA «Камеры» (карточка WebRTC с тремя потоками и кнопками).

## 1. Что есть сейчас в Atom Home v1.2.1
- Плитка 2×2 на главной: живое видео 720p (модуль `camera_go2rtc`, MSE через ingress аддона), LIVE, подпись. Лист: только видео и переключатель SD/HD — **ни одной функции камеры**.
- Функции камеры живут в другом HA-устройстве («Подъезд · Камера (Xiaomi C700)», xiaomi_miot) и рассыпаны по «Системам» **14 отдельными плитками-выключателями** («Время на картинке», «ИИ: лица», «Патрулирование»…) — мусор, который надо убрать в карточку камеры.
- Выбор потока: в листе SD (720p H.264, быстро, работает везде) / HD (1080p H.265 — Chrome на Android и приложение HA не декодируют → серый переключатель). Разговор (микрофон) только на панели HA «Камеры» (карточка WebRTC).

## 3. Карточка в Atom Home — что показываем
Принцип UX-GUIDE: состояние важнее действия; главное читается с 2 м; рискованное — через подтверждение; никаких entity_id.

### Плитка (главная 2×2, комната, «Системы → Камеры»)
- Живое видео (SD) с LIVE; при закрытом объективе — тёмная плитка «Объектив закрыт» (без видео, серый глиф), при недоступности — 55 % прозрачности.
- Подпись: «Камера подъезда»; вторая строка — состояние одним словом: «Слежение» / «Патруль» / «Ночной режим» / «Без звука» (приоритет слева направо).

### Лист (планшет: видео слева, панель справа; телефон: видео сверху, прокрутка ниже)
1. **Сцена**: видео, сверху LIVE + время кадра, справа SD/HD и «во весь экран». Под видео четыре круглые кнопки, как в Mi Home: **Снимок** (кадр camera_proxy → сохранить), **Разговор** (этап 2, WebRTC с микрофоном), **SD/HD**, **Полный экран**.
2. **Герой**: строка состояния «Включена · Ночной режим авто · Слежение за человеком».
3. **Питание**: большая кнопка «Закрыть объектив» / «Открыть объектив» (switch.entrance_camera_power), выключение — с подтверждением (камера безопасности).
4. **Режимы** (чипы): Ночное видение Авто / Вкл / Выкл; HDR Выкл / Вкл / Авто.
5. **Поворот и слежение**: Слежение за человеком, Слежение за питомцем, Патрулирование (панорама); «Избранные позиции» — чипы из fav_area (пока пусто → подсказка «Задайте позиции в Mi Home»; этап 2).
6. **Детекция** (свёртка, открыта): Детекция движения (главный выключатель) → чувствительность, интервал тревог, время (этап 2); ИИ: человек, движение (+чувствительность), питомец, лица, плач ребёнка, громкий звук (+чувствительность); Геозона и Жестовые вызовы — этап 2.
7. **Звук**: громкость (слайдер 0–100), Без звука.
8. **Изображение**: Временная метка, Коррекция искажений, Поворот 0°/180°, Цветное ночное видение, Индикатор.
9. **Запись и хранилище**: Запись на карту (Нет / По движению / Всегда); Карта microSD — статус словами («Нет карты»), свободно/занято; NAS — этап 2.
10. **Диагностика** (свёртка): модель, прошивка 5.3.2_0808, IP, MAC, кодек H.265 + OPUS, 4K; **Перезагрузить камеру** (кнопка с подтверждением, этап 2).

## 4. Как склеить видео и функции (архитектура)
Сейчас карточка = одна сущность HA. Камера C700 — это **два HA-устройства**: Generic Camera (видео через go2rtc) и xiaomi_miot (функции). Предложение:
- Модуль `camera_go2rtc` получает роли управления: `power, night, hdr, tracking, petTracking, cruise, motion, motionSens, alarmInterval, aiHuman, aiMotion, aiPet, aiFace, aiBabycry, aiSound, soundSens, moveSens, volume, mute, watermark, distortion, rotation, colorNight, indicator, recording, sdStatus, sdFree, sdUsed, info`. `detect()` ищет их по устройству xiaomi_miot с моделью `chuangmi.camera.*` в той же комнате (по суффиксам `_power`, `_night_mode`…), владелец может поправить в конфигураторе.
- Сущности, занятые модулем, **исчезают из «Систем»** как отдельные плитки (как уже сделано для кормушки).
- Лист камеры рисует модуль (`Sheet` в ModuleDef — новое поле рядом с `Player`), а не общий DeviceSheet.
- Общий случай «устройство-спутник» (любая камера с функциями в другом устройстве) — тем же механизмом ролей; для звонка Aqara G4 (следующая карточка) роли другие: ring-событие, движение, батарея, mute×3, identify.

## 5. Этапы
1. **v1.3.0 — карточка на существующих сущностях**: склейка, лист по п. 3 (без разговора, позиций, времени детекции, перезагрузки), снимок кадра, уборка 14 плиток из «Систем», проверка на OPPO Pad / OnePlus 13R / OnePlus Open, снимки в `frontend/evidence/camera-c700/`.
2. **v1.3.x — новые сущности в HA** (шаблоны xiaomi_miot): перезагрузка (A2.2), окно времени детекции (S5.P4–5), избранные позиции (S10), геозона (S26), жесты (S8.P4), NAS (S25), «Защитник семьи» (S27, чтение); события камеры (кто-то появился, питомец, шум, патруль) — лента в листе.
3. **Разговор** (микрофон): WebRTC через go2rtc с отправкой звука (как карточка WebRTC на панели «Камеры»); через Nabu Casa нужен TURN — отдельное исследование.

Не делаем: облачное наблюдение и архив Xiaomi (платно), ручной PTZ (нет в MIoT; в Mi Home он по закрытому P2P), калибровка гиростабилизатора.
