# Дизайн-система «homeOS» (v0.8) — по Apple HomeView, лицо Home Modular

Источники (28.10.2026): страница apple.com/apple-homeview (раздел «Everything connected and under one roof» — настенный HomeView с лицом Home Modular; карусель лиц), пресс-релиз Apple Newsroom «Meet Apple HomeView» с изображениями `Apple-HomeView-home-touch` (лицо Home Modular на светлом фоне), `Apple-HomeView-wall-mounted` (то же лицо на тёмных бирюзовых обоях), `Apple-HomeView-collection-of-faces` (лицо «68» с термостатом и сценами). Копии изображений: `private/references/homeview/` (вне репозитория). Hands-on в прессе (MacRumors, AppleInsider, TechRadar) описывают поведение: лицо Home Modular даёт «быстрый доступ к избранным аксессуарам», Home Camera — до девяти потоков, интерфейс упрощается на расстоянии.

## Что взято 1:1
| Элемент оригинала | Как в Atom Home |
|---|---|
| Одна сетка квадратных модулей на всём экране, 3×3 на 7-дюймовом экране, зазор ≈ 10 px, радиус ≈ 22 px | `.ah-face.ah-grid`: 3 колонки на телефоне, 4 на планшете в портрете, 6–7 в ландшафте; `aspect-ratio:1`, `gap:10px`, `border-radius:22px`, плотная раскладка (`grid-auto-flow:dense`) |
| Модуль аксессуара: крупный глиф по центру, под ним имя полужирным и комната тоньше | `AccessoryTile`: глиф 34 px, имя 14/600, вторая строка 12 px (комната для управляемого, значение для датчика) |
| Активные модули лавандовые с белым глифом, неактивные — светло-серые с тёмно-серым глифом (светлое лицо) | токены `--ah-tint:#cfc9f4` / `--ah-tile:#e3e3e8`, глиф `#6e6e73` → белый на активной |
| На тёмных обоях модули — матовое стекло, глиф в светлом круге | тёмная тема: `--ah-tile:#ffffff24` + `backdrop-filter:blur(18px)`, круг глифа `#ffffff2e`, обои — бирюзовый градиент с диагональным узором |
| Термостат 2×2: большое число по центру, шевроны ∨ ∧ в нижних углах, под числом имя и комната | `ThermostatTile`: `grid-column/row: span 2`, число `clamp(40px,30cqw,96px)` весом 400, шевроны 40 px, «сейчас N°» под числом |
| Часы 1×1: аналоговый циферблат с цифрами лавандового цвета, чёрные стрелки | `ClockTile` (SVG), цифры `--ah-accent`, стрелки `--ah-ink`; обновление каждые 20 с |
| Камера: кадр заполняет модуль | `CameraTile` 2×2 для камеры с живым потоком (go2rtc), 1×1 для остальных; подпись в нижнем градиенте |
| Сцена: глиф + имя + «Scene» | `SceneTile` для кнопок владельца, подпись «Кнопка» |
| Показания (температура/давление/энергия) | `ValueTile`: маленький цветной круг-иконка, крупное число, подпись; компактные карточки модулей (давление котла) рендерятся так же |
| Шрифт SF, антиалиасинг | `-apple-system, "SF Pro Text", system-ui…` |

## Чего в оригинале нет и как решено
- Навигация: у HomeView лица листаются свайпом; у нас вкладки Дом · Комнаты · Системы · Настройка (рельс иконок 88 px на планшете, матовый таб-бар на телефоне). Разделы Климат/Свет/Уборка/Энергия/Системы — сегменты внутри «Системы».
- Заголовок экрана небольшой (26 px) — на лице HomeView заголовка нет, но нам нужны название дома и дата.
- Комната: пилюли показаний сверху и те же модули по группам; плитка комнаты на экране «Комнаты» — фото с температурой.
- Карточка устройства: нижний лист (телефон) / центральное окно (планшет) в тех же токенах.

## Токены
Светлая тема: фон `#f2f2f6`, модуль `#e3e3e8`, активный `#cfc9f4`, акцент `#7b74d8`, текст `#1c1c1e`, вторичный `#8a8a8e`, группы списков `#ffffff`.
Тёмная тема: обои бирюзовые (`#1f5658 → #102c30`), модуль `#ffffff24` + blur, активный `#ffffff52`, акцент `#b9b3ff`, текст `#ffffff`, вторичный `#ffffffb3`.
Состояния: тревога (протечка/сигнализация) — `#ff3b30cc`; недоступно — `opacity:.55`.
